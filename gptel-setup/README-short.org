#+TITLE: Использование gptel с Ollama

Backend — Ollama. Принцип: *модель + директива + запрос → ответ*.

* Модели

| Модель              | Назначение                  | Команда              | Клавиши   |
|---------------------+-----------------------------+----------------------+-----------|
| =qwen2.5-coder:14b= | Основная (программирование) | =my/gptel-coder-14b= | =C-c g 1= |
| =qwen2.5-coder:7b=  | Быстрая                     | =my/gptel-coder-7b=  | =C-c g 7= |
| =qwen3:30b=         | Крупная универсальная       | =my/gptel-qwen=      | =C-c g q= |
| =beam:cloud=        | Облачная                    | =my/gptel-beam=      | =C-c g b= |

По умолчанию: =qwen2.5-coder:14b=.

* Директивы

Задают системные инструкции. Доступные: =common-lisp=, =emacs-lisp=, =linux=, =bash=.

- Выбор: =C-c g d= (=my/gptel-select-directive=)
- Текущая: =C-c g D= (=my/gptel-current-directive=)

Устанавливаются локально для буфера.

* Основные команды

| Действие          | Команда         | Клавиши   |
|-------------------+-----------------+-----------|
| Открыть чат       | =gptel=         | =C-c g c= |
| Отправить запрос  | =gptel-send=    | =C-c g s= |
| Отправить из чата | =gptel-send=    | =C-c RET= |
| Rewrite/refactor  | =gptel-rewrite= | =C-c g r= |
| Меню              | =gptel-menu=    | =C-c g m= |

* Типичный рабочий процесс

#+begin_example
C-c g 1        -> qwen2.5-coder:14b
C-c g d        -> common-lisp
C-c g c        -> открыть чат
Написать вопрос
C-c RET        -> отправить
#+end_example

Для работы с кодом в текущем буфере: выделить фрагмент → =C-c g r=.

* Краткая памятка

- Модели: =C-c g 1/7/q/b=
- Директивы: =C-c g d= (выбрать), =C-c g D= (показать)
- Чат: =C-c g c=, отправка =C-c RET=
- Отправка из буфера: =C-c g s=
- Rewrite: =C-c g r=
- Меню: =C-c g m=
