#+TITLE: Ollama через SSH
#+SUBTITLE: Спокойная и безопасная организация удалённой работы с моделями
#+LANGUAGE: ru
#+OPTIONS: toc:2 num:nil

* Назначение

Когда вычислительная машина с GPU стоит отдельно от рабочего компьютера,
нет особой причины делать HTTP API Ollama доступным всей локальной сети.
Гораздо аккуратнее оставить Ollama локальным сервисом на сервере, а доступ
к нему предоставить через SSH-туннель.

В описанной конфигурации используются две машины:

- =mnasoft-00= — Linux-сервер, на котором работает Ollama;
- =DESKTOP-JVRHMFB= — Windows/MSYS2, где работают Emacs и Ollama Buddy.

Адрес сервера: =192.168.0.140=.

#+begin_example
DESKTOP-JVRHMFB                         mnasoft-00

Emacs / Ollama Buddy
        |
        v
127.0.0.1:11434
        |
        |       SSH tunnel
        +-----------------------------> 127.0.0.1:11434
                                                |
                                                v
                                              Ollama
#+end_example

* 1. Ограничиваем Ollama локальным интерфейсом

На =mnasoft-00= Ollama должна слушать =127.0.0.1:11434=.

#+begin_src sh
sudo systemctl edit ollama
#+end_src

#+begin_src conf
[Service]
Environment="OLLAMA_HOST=127.0.0.1:11434"
#+end_src

#+begin_src sh
sudo systemctl daemon-reload
sudo systemctl restart ollama.service
ss -ltnp | grep 11434
curl http://127.0.0.1:11434/api/version
#+end_src

* 2. Первый SSH-туннель

На =DESKTOP-JVRHMFB=:

#+begin_src sh
ssh -N -L 11434:127.0.0.1:11434 mna@192.168.0.140
#+end_src

Во втором терминале:

#+begin_src sh
curl http://127.0.0.1:11434/api/tags
#+end_src

* 3. Авторизация по SSH-ключу

#+begin_src sh
ssh-keygen -t ed25519
ssh-copy-id -i ~/.ssh/id_ed25519.pub mna@192.168.0.140
#+end_src

Проверка:

#+begin_src sh
ssh -i ~/.ssh/id_ed25519 \
    -o IdentitiesOnly=yes \
    mna@192.168.0.140
#+end_src

* 4. Конфигурация ~/.ssh/config

#+begin_src ssh-config
Host ollama
    HostName 192.168.0.140
    User mna
    IdentityFile ~/.ssh/id_ed25519
    IdentitiesOnly yes

    LocalForward 127.0.0.1:11434 127.0.0.1:11434
    ExitOnForwardFailure yes

    ServerAliveInterval 30
    ServerAliveCountMax 3

    ControlMaster auto
    ControlPath ~/.ssh/ollama-control.sock
    ControlPersist yes
#+end_src

* 5. Безопасность

Ollama принимает соединения только на loopback-интерфейсе
=127.0.0.1:11434=. Удалённый доступ осуществляется через SSH.
Локальный конец туннеля также привязан только к =127.0.0.1:11434=.

** Приватный ключ

Файл =~/.ssh/id_ed25519= является приватным ключом. На сервер передаётся
только публичная часть =~/.ssh/id_ed25519.pub=.

#+begin_src sh
chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_ed25519
chmod 644 ~/.ssh/id_ed25519.pub
#+end_src

** Проверка ключа сервера

При первом соединении следует проверить fingerprint ключа сервера перед его
подтверждением. После подтверждения ключ сохраняется клиентом для последующих
соединений.

** Ограничение локального forwarding

Используется явная привязка к loopback:

#+begin_src ssh-config
LocalForward 127.0.0.1:11434 127.0.0.1:11434
#+end_src

Без необходимости не следует заменять её привязкой к =0.0.0.0=.

** ControlMaster

Управляющий сокет расположен внутри =~/.ssh=:

#+begin_src ssh-config
ControlMaster auto
ControlPath ~/.ssh/ollama-control.sock
ControlPersist yes
#+end_src

Проверка и остановка выполняются штатными командами:

#+begin_src sh
ssh -O check ollama
ssh -O exit ollama
#+end_src

** Не открывать Ollama одновременно через LAN и SSH

Если используется SSH-туннель, предпочтительно оставить:

#+begin_example
OLLAMA_HOST=127.0.0.1:11434
#+end_example

а не =OLLAMA_HOST=0.0.0.0:11434=.

* 6. Запуск туннеля

Диагностика:

#+begin_src sh
ssh -N ollama
#+end_src

Фоновый режим:

#+begin_src sh
ssh -f -N ollama
#+end_src

* 7. Управление туннелем

#+begin_src sh
ssh -O check ollama
ssh -O exit ollama
#+end_src

Повторный запуск:

#+begin_src sh
ssh -f -N ollama
#+end_src

* 8. Проверка Ollama через туннель

#+begin_src sh
curl http://127.0.0.1:11434/api/version
curl http://127.0.0.1:11434/api/tags
#+end_src

* 9. Ollama Buddy

Основная настройка находится в =ollama-buddy-setup.el=:

#+begin_src emacs-lisp
(use-package ollama-buddy
  :ensure t
  :bind
  (("C-c o" . ollama-buddy-role-transient-menu)
   ("C-c O" . ollama-buddy-transient-menu))
  :custom
  (ollama-buddy-host "localhost")
  (ollama-buddy-port 11434))
#+end_src

** RAG

#+begin_src emacs-lisp
(use-package ollama-buddy-rag
  :after ollama-buddy
  :config
  (dolist (ext '("lisp" "cl" "asd"))
    (add-to-list 'ollama-buddy-rag-file-extensions ext)))
#+end_src

** Common Lisp preset

#+begin_src emacs-lisp
(require 'ollama-buddy--preset__common-lisp)
#+end_src

Preset содержит специализированные команды для анализа, отладки,
рефакторинга, документирования и тестирования Common Lisp-кода, а также
работы с ASDF, макросами, Project и RAG.

* 10. Установка конфигурации Emacs

Архив содержит:

#+begin_example
ollama-buddy-setup/
├── README.org
├── ollama-buddy-setup.el
└── ollama-buddy--preset__common-lisp.el
#+end_example

В MSYS2 архив из =C:\Users\mnaso\Downloads\= можно распаковать прямо в
=~/elisp=:

#+begin_src sh
tar -xJvf \
  /c/Users/mnaso/Downloads/ollama-buddy-setup.tar.xz \
  -C ~/elisp
#+end_src

Если каталог ещё не находится в =load-path=:

#+begin_src emacs-lisp
(add-to-list
 'load-path
 (expand-file-name "~/elisp/ollama-buddy-setup/"))
#+end_src

Загрузка конфигурации:

#+begin_src emacs-lisp
(require 'ollama-buddy-setup)
#+end_src

* 11. Повседневная работа

#+begin_src sh
ssh -f -N ollama
ssh -O check ollama
curl http://127.0.0.1:11434/api/version
#+end_src

После работы:

#+begin_src sh
ssh -O exit ollama
#+end_src

* 12. Диагностика

** Порт 11434 уже занят

#+begin_src sh
netstat -ano | grep 11434
#+end_src

** Подробная диагностика SSH

#+begin_src sh
ssh -vvv -N ollama
#+end_src

** Фактическая SSH-конфигурация

#+begin_src sh
ssh -G ollama | grep -E \
  '^(hostname|user|identityfile|localforward|exitonforwardfailure|control)'
#+end_src

** Проверка Emacs Lisp

#+begin_src sh
emacs -Q --batch \
  --eval '(with-temp-buffer
            (insert-file-contents
             "~/elisp/ollama-buddy-setup/ollama-buddy--preset__common-lisp.el")
            (emacs-lisp-mode)
            (check-parens))'
#+end_src

** Особенность MSYS2

#+begin_src sh
MSYS2_ARG_CONV_EXCL='*' tasklist.exe /FI "PID eq 1234"
#+end_src

* 13. Краткая памятка

#+begin_src sh
# Запустить туннель
ssh -f -N ollama

# Проверить SSH master
ssh -O check ollama

# Проверить Ollama
curl http://127.0.0.1:11434/api/version

# Получить список моделей
curl http://127.0.0.1:11434/api/tags

# Остановить туннель
ssh -O exit ollama
#+end_src

* Заключение

Ollama остаётся локальным сервисом вычислительной машины. SSH обеспечивает
удалённый доступ, а Emacs и Ollama Buddy продолжают работать с привычным
=localhost=.

Конфигурация Emacs остаётся небольшой:

#+begin_example
~/elisp/ollama-buddy-setup/
├── README.org
├── ollama-buddy-setup.el
└── ollama-buddy--preset__common-lisp.el
#+end_example

Для повседневной работы достаточно запустить:

#+begin_src sh
ssh -f -N ollama
#+end_src

а затем завершить туннель:

#+begin_src sh
ssh -O exit ollama
#+end_src
